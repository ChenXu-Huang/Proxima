# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

### Added

- Modern popup for configuring the native Firefox and Chrome proxy settings.
- Five connection modes: direct, manual, system, PAC, and WPAD auto-detect.
- Manual HTTP, HTTPS, SOCKS4, and SOCKS5 configuration with HTTPS sharing, bypass list, SOCKS DNS, and saved-password authentication options.
- Read-back of the browser's actual configuration, controller detection, and actionable policy/private-window/read-error states.
- Draft autosave and restore.
- English and Chinese UI, automatic light/dark theming, and keyboard-accessible controls.
